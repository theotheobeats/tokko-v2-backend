# Monad — Style Reference
> editorial tech journal on warm paper

**Theme:** light
**Best for:** warm aesthetic, tech, editorial, content-driven brands

Monad reads like a printed journal left on a wooden desk: warm cream paper, deep espresso ink, and serif headlines that carry the authority of a magazine masthead. Color is used like an editor's highlighter — a single amber (#d97706) marks links and key phrases, everything else lives in warm neutrals. Cards sit on the paper with thin rules and soft 12px corners, like clippings pinned to a board.

## Color Palette

| Role | Value | Usage |
|------|-------|-------|
| Warm Paper | `#faf7f2` | Page canvas — tactile, never pure white |
| Espresso Ink | `#292524` | Headlines, primary text |
| Warm Gray | `#78716c` | Body copy, captions |
| Amber Mark | `#d97706` | Links, pull-quote marks, key accents |
| Card Cream | `#fffdf9` | Card surfaces |
| Hairline | `#e7e0d5` | Borders, column rules |
| Highlight | `#fef3e2` | Highlighted passages, soft panels |

## Typography

- **Headlines**: Georgia (substitute: serif), weight 700, 44-64px, tracking -0.01em
- **Body**: Inter (substitute: system-ui), weight 400, 16-17px, line-height 1.7
- Eyebrow/kicker: 13px, weight 600, uppercase, 0.06em tracking, in Amber
- Pull quotes: Georgia italic, 22-26px

## Spacing & Shapes

- Card radius: 12px
- Button radius: 8px
- Section gap: 88-120px
- Page max-width: 1080px (narrower, like a journal column)
- 1px #e7e0d5 hairline rules; no shadows

## Key Patterns

- Hero: kicker label → serif headline → deck paragraph → amber-text CTA
- Cards: cream on warm paper, 12px radius, hairline border
- Pull quotes: oversized serif with amber quotation mark, set apart by rules
- Alternate #faf7f2 and #fef3e2 panels for editorial rhythm
- Serif headlines everywhere — never sans for display type

## Do's
- Serif display type for all headlines — it's the identity
- Warm paper canvas (#faf7f2), never pure white
- Amber #d97706 sparingly — one accent, like a highlighter
- Hairline rules to separate content, not boxes

## Don'ts
- No gradients or shadows — flat ink on paper
- No startup clichés (no floating 3D shapes, no neon)
- No sans-serif headlines
- No cool blues or grays — stay warm
