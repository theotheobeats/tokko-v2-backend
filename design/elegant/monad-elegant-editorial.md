# Monad — Style Reference
> editorial tech journal on warm paper

**Theme:** light
**Best for:** tech, service, editorial

## Color Palette
Warm paper, deep ink. Journal/magazine palette with tech-blue accents.

## Typography
Editorial serif headlines + clean sans body. Magazine layout.

## Spacing & Shapes
Journal grid. Clean columns. Moderate card radii.

## Key Patterns
Tech content as editorial magazine. Serif headlines. Multi-column layouts. Pull quotes.

## Do's
Editorial serif for authority. Magazine grid layouts. Warm paper.

## Don'ts
No startup clichés. No gradients. No dark mode.
