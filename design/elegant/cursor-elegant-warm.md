# Cursor — Style Reference
> warm dark editor, amber syntax glow

**Theme:** dark
**Best for:** warm aesthetic, tech, developer tools, creative software

Cursor feels like a beloved code editor at golden hour: a warm charcoal canvas with amber (#f5a623) accents that glow like syntax highlighting. Type is clean and modern against the warm dark, and surfaces have soft 12px rounding like editor tabs. It's technical but inviting — the warmth comes from amber light on dark wood tones, not cold blue.

## Color Palette

| Role | Value | Usage |
|------|-------|-------|
| Warm Charcoal | `#1a1714` | Page canvas |
| Editor Panel | `#241f1a` | Card surfaces |
| Amber Glow | `#f5a623` | CTAs, syntax accents, highlights |
| Cream Text | `#f5efe6` | Headlines, primary text |
| Warm Gray | `#a89f93` | Body copy |
| Hairline | `#332b23` | Borders, dividers |
| Amber Tint | `rgba(245,166,35,0.12)` | Highlight washes |

## Typography

- **Primary**: Inter (substitute: system-ui), weights 400-600
- Display: 48-64px, weight 600, tracking -0.02em
- Section heading: 30-36px, weight 600
- Body: 15-16px, weight 400, line-height 1.65
- Code/labels: 13px, ui-monospace, amber for emphasis

## Spacing & Shapes

- Card radius: 12px (soft editor-tab feel)
- Button radius: 8px
- Section gap: 88-120px
- Page max-width: 1120px
- 1px #332b23 hairlines; amber glow on CTAs

## Key Patterns

- Hero: warm cream headline → amber CTA with soft glow (box-shadow: 0 0 24px rgba(245,166,35,0.3))
- Cards: #241f1a warm panels, 12px radius, hairline border
- CTAs: filled amber #f5a623 with dark text
- Code snippets/labels: monospace in amber on dark
- Alternate charcoal and editor-panel tones for rhythm

## Do's
- Warm dark canvas (brown-tinted, not blue-black)
- Amber #f5a623 as the single warm accent
- Soft 12px rounding on cards
- Monospace accents for technical credibility

## Don'ts
- No cold blues or clinical grays
- No bright white surfaces
- No shadows except amber glow
- No multiple accent colors
