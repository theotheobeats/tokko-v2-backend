# Cursor — Style Reference
> Warm parchment atelier lit by monitor glow

**Theme:** light
**Best for:** tech, craft, editorial

## Color Palette
Parchment/cream canvas. Warm amber monitor glow. Deep brown/charcoal text.

## Typography
Clean sans + editorial serif accents. Warm, approachable.

## Spacing & Shapes
Soft rounded cards. 12-16px radii. Subtle warm shadows.

## Key Patterns
AI coding tool as warm atelier. Code blocks on parchment. Amber glow highlights.

## Do's
Warm parchment #fdfbf7 backgrounds. Amber/coral accents. Code blocks as decorative texture.

## Don'ts
No cold blues. No sterile white. No harsh contrasts.
