# Awesomic — Style Reference
> editorial zinc grid with Bauhaus precision

**Theme:** light
**Best for:** design, craft, fashion

## Color Palette
Zinc/metallic grays. Bauhaus primary accents (red, blue, yellow). White space.

## Typography
Geometric sans-serif. Bauhaus proportions. Grid-based.

## Spacing & Shapes
Zinc grid layouts. Bauhaus geometry. Sharp but not harsh.

## Key Patterns
Design marketplace as Bauhaus catalog. Grid systems. Primary color accents. Geometric precision.

## Do's
Geometric grids. Bauhaus color accents (red/blue/yellow). Zinc/metallic tones.

## Don'ts
No organic shapes. No pastels. No asymmetrical chaos.
