# Ui — Style Reference
> clinical blueprint on frosted paper

**Theme:** light
**Best for:** warm aesthetic, tech, service, design tools, SaaS

Ui is a blueprint drafted on frosted glass: pale cool canvas, hairline blueprint-blue rules, and typography set with machinist precision. The page feels like a spec sheet brought to life — exact spacing, monochrome cool grays, and a single technical blue (#2563eb) marking every interactive element like an engineer's annotation. Corners are tight (8px), borders are hairline, and nothing casts a shadow.

## Color Palette

| Role | Value | Usage |
|------|-------|-------|
| Blueprint Blue | `#2563eb` | CTAs, links, annotation accents |
| Ink Navy | `#0f172a` | Headlines, primary text |
| Steel Gray | `#64748b` | Body copy, captions |
| Frost Canvas | `#f8fafc` | Page background |
| Glass Card | `#ffffff` | Card surfaces |
| Hairline | `#e2e8f0` | Borders, grid rules |
| Wash Blue | `#eff6ff` | Highlight panels, code/spec blocks |

## Typography

- **Primary**: Inter (substitute: system-ui), weights 400-600
- Display: 48-64px, weight 600, tracking -0.025em
- Section heading: 30-36px, weight 600
- Body: 15-16px, weight 400, line-height 1.65
- Spec/label text: 12-13px, weight 500, uppercase, 0.05em tracking

## Spacing & Shapes

- Card radius: 8px (tight, technical)
- Button radius: 8px
- Tag radius: 6px
- Section gap: 80-112px
- Page max-width: 1200px
- 1px #e2e8f0 hairlines everywhere; no shadows

## Key Patterns

- Hero: left-aligned, spec-label eyebrow → crisp headline → outlined + filled button pair
- Cards: white on frost canvas, 8px radius, hairline border, flat
- Wash-blue panels (#eff6ff) for feature highlights and testimonials
- Buttons: 8px radius, filled #2563eb primary, hairline-outline secondary
- Grid rhythm: sections divided by 1px rules, generous 96px gaps

## Do's
- #2563eb for all interactive elements — one technical blue
- 8px radius consistently — the blueprint edge
- Hairline borders instead of shadows for structure
- Wash-blue panels to add cool depth without new colors

## Don'ts
- No warm colors — the palette stays cool and clinical
- No drop shadows or blur glows
- No playful fonts, emojis, or rounded-pill buttons
- No gradients on surfaces
