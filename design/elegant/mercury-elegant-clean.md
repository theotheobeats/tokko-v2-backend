# Mercury — Style Reference
> alpine banking at blue hour

**Theme:** light
**Best for:** warm aesthetic, finance, service, professional trust

Mercury treats a landing page like a private bank at dawn: a cool porcelain-white canvas, deep ink text, and a single alpine blue (#4e7fff) that appears only where money moves. Everything is calm, rounded just enough to feel human, and spaced like a lobby with too much marble. The confidence comes from restraint — one blue, soft 16px cards, and enormous quiet headlines.

## Color Palette

| Role | Value | Usage |
|------|-------|-------|
| Alpine Blue | `#4e7fff` | Primary CTA fill, active links, key accents |
| Deep Ink | `#0d1530` | Headlines, primary text |
| Slate Body | `#5b6478` | Body paragraphs, secondary text |
| Porcelain | `#fbfcff` | Page canvas |
| Card White | `#ffffff` | Card surfaces |
| Frost Line | `#e6eaf4` | Hairline borders, dividers |
| Ice Tint | `#eef3ff` | Highlight panels, hover states |

## Typography

- **Primary**: Inter (substitute: system-ui), weights 400-600
- Display: 56-72px, weight 600, tracking -0.03em — big, quiet, confident
- Section heading: 32-40px, weight 600
- Body: 16px, weight 400, line-height 1.6
- Eyebrow labels: 13px, weight 600, uppercase, 0.08em tracking, in Alpine Blue

## Spacing & Shapes

- Card radius: 16px
- Button radius: 9999px (pill — approachable trust)
- Input radius: 12px
- Section gap: 96-128px
- Page max-width: 1120px
- Hairline borders: 1px #e6eaf4, no shadows

## Key Patterns

- Hero: eyebrow label → 64px ink headline → one pill CTA → muted subtext
- Cards: pure white on porcelain canvas, 1px frost border, zero shadow
- Alternate sections between #fbfcff and #eef3ff for gentle rhythm
- Buttons: pill, filled #4e7fff, generous 16px 32px padding
- Trust elements: logos and stats in Slate, never competing with the blue

## Do's
- Reserve #4e7fff for exactly one primary action per viewport
- Pair porcelain canvas with pure white cards for soft depth
- Keep headlines huge and quiet — weight 600, tight tracking
- Use ice-tint panels to break up long pages

## Don'ts
- No warm earth tones (no orange, tan, brown)
- No drop shadows — depth comes from tint and border only
- No gradients on UI chrome
- No more than one accent color
