# ElevenLabs — Style Reference
> Warm cream editorial with whispered headlines

**Theme:** light
**Best for:** warm aesthetic, editorial, design-forward brands

A Bauhaus studio notebook — eggshell paper, black ink, a single violet and orange spark for product moments. Whisper-weight Waldenburg at 300 carves display headlines with extreme tightness (-0.02em), while Inter at 400/500 carries everything else with calm neutrality. Two accent sparks — vivid violet #0447ff and vivid orange #ff4704 — only ignite inside product visuals, never as UI chrome. Components stay flat or barely elevated with hairline 1px borders, generous 20px radii on cards, and fully-pilled 9999px buttons. The system feels like a Bauhaus studio on cream paper: restrained, editorial, and technically precise.

## Color Palette

| Role | Value | Usage |
|------|-------|-------|
| Eggshell | `#fdfcfc` | Page canvas — warm off-white, reads as paper |
| Warm Taupe | `#f5f3f1` | Section bands, feature cards |
| Stone | `#ebe8e4` | Hairline borders, dividers |
| Ink Black | `#000000` | Primary text, buttons, nav |
| Graphite | `#44403b` | Strong secondary text |
| Smoke | `#777169` | Body text, descriptions |
| Ash | `#a59f97` | Faintest helper text |
| Violet Spark | `#0447ff` | Product visuals ONLY — never UI |
| Ember Orange | `#ff4704` | Product visuals ONLY — never UI |

## Typography

- **Display**: Waldenburg (substitute: Inter weight 300), weight 300, 32-48px, -0.02em tracking
- **Body/Nav**: Inter, weights 400-500
- Display: 48px, weight 300, tracking -0.96px — the whisper-weight is anti-convention
- Body: 16px, weight 400, line-height 1.5, +0.01em tracking

## Spacing & Shapes

- Card radius: 20-24px
- Button radius: 9999px (full pill)
- Input radius: 4px
- Section gap: 96-125px
- Page max-width: 1280px

## Key Patterns

- Hero: left-aligned 48px Waldenburg headline, right-aligned body description
- Feature cards: #f5f3f1 taupe fill, 20px radius, no shadow
- Pill buttons: #000000 fill, white text, 9999px radius — most recognizable component
- Hairline dividers: 1px #ebe8e4 — preferred over whitespace
- Audio spheres: large gradient circles (violet→orange→pink) as product visuals
- Surfaces stack: eggshell → taupe → stone — never pure white

## Do's
- Waldenburg at weight 300 for all display — the whisper-weight is the signature
- 9999px radius on all buttons — pill shape is non-negotiable
- #000000 filled buttons paired with #fdfcfc outline buttons
- Violet/orange reserved exclusively for product visuals
- 1px #ebe8e4 hairline dividers for section separation

## Don'ts
- No bolding Waldenburg — weight 300 is the brand's most distinctive choice
- No violet/orange in buttons, links, or UI chrome
- No heavy drop shadows — near-invisible 1px only
- No sharp corners below 8px
- No pure white `#ffffff` — always use `#fdfcfc` eggshell
