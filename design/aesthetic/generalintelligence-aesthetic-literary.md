# General Intelligence — Style Reference
> literary broadsheet with ink and vermillion

**Theme:** light
**Best for:** bold aesthetic, editorial, research, ideas-driven brands

General Intelligence is a literary broadsheet: cream newsprint canvas, dense black serif headlines, and a single vermillion (#e63946) that strikes like an editor's red pen. The layout is unapologetically text-forward — multi-column rhythms, drop caps, pull quotes, and thick rules. It's bold through typography and contrast, not graphics.

## Color Palette

| Role | Value | Usage |
|------|-------|-------|
| Newsprint Cream | `#f5f1e8` | Page canvas |
| Ink Black | `#141312` | Headlines, body text |
| Vermillion | `#e63946` | CTAs, emphasis, drop caps |
| Warm Gray | `#6b675f` | Secondary text, captions |
| Rule Black | `#141312` | Thick 2px section rules |
| Highlight | `#f9e8e8` | Pull-quote and emphasis panels |

## Typography

- **Headlines**: Georgia / Playfair (substitute: serif), weight 700-900, 52-80px
- **Body**: Source Serif / Georgia, weight 400, 17-18px, line-height 1.7
- Kickers: 12px, weight 700, uppercase, 0.12em tracking, vermillion
- Pull quotes: serif italic, 24-30px

## Spacing & Shapes

- Card radius: 0-4px (near-sharp, print-like)
- Button radius: 4px
- Section gap: separated by 2px black rules, not just space
- Page max-width: 1200px
- Thick rules and column lines as structure

## Key Patterns

- Hero: massive serif headline, drop-cap first letter in vermillion, red CTA
- Vermillion used to strike key words and primary action only
- Pull quotes set apart by thick rules, oversized serif italic
- Multi-column editorial grids with vertical hairline separators
- Cards/panels: flat cream with 2px black border, no shadow

## Do's
- Serif type at large sizes for authority
- Vermillion sparingly — drop caps, key words, one CTA
- Thick black rules as section dividers
- Dense, confident, text-first layouts

## Don'ts
- No rounded soft corners — keep print-sharp
- No gradients, shadows, or glass
- No pastel or second accent color
- No sparse startup-style hero — be dense and editorial
