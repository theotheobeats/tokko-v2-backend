# Monopo — Style Reference
> avant-garde studio, acid green on off-black

**Theme:** dark
**Best for:** bold aesthetic, creative studios, fashion, experimental brands

Monopo is an avant-garde gallery at night: off-black canvas, acid green (#c8f31d) slicing through like a highlighter, and oversized experimental type that ignores convention. Layouts break the grid — rotated labels, overlapping elements, huge numerals. It's bold through attitude: high contrast, unexpected placement, and that single acidic green.

## Color Palette

| Role | Value | Usage |
|------|-------|-------|
| Off-Black | `#0c0c0a` | Page canvas |
| Panel | `#161613` | Card surfaces |
| Acid Green | `#c8f31d` | CTAs, highlights, experimental accents |
| Bone White | `#f2f2ec` | Headlines, primary text |
| Ash Gray | `#8f8f85` | Body copy |
| Hairline | `#26261f` | Borders |
| Acid Tint | `rgba(200,243,29,0.1)` | Highlight washes |

## Typography

- **Primary**: Inter / Archivo (substitute: system-ui), weights 400-900
- Display: 64-96px, weight 800-900, tracking -0.03em — enormous, occasionally uppercase
- Section heading: 36-48px, weight 800
- Body: 15-16px, weight 400, line-height 1.6
- Labels: 12px, weight 700, uppercase, 0.1em tracking

## Spacing & Shapes

- Card radius: 4px (near-sharp, gallery edge)
- Button radius: 0-4px
- Section gap: 100-140px (dramatic voids)
- Page max-width: 1280px
- 1px #26261f hairlines; acid-green elements can break the grid

## Key Patterns

- Hero: massive weight-900 headline, acid-green accent word, sharp CTA
- Oversized numerals and rotated vertical labels as editorial texture
- Cards: #161613 near-sharp panels, hairline border
- CTAs: solid acid green with black text — maximum contrast
- Asymmetric layouts with intentional overlap and tension

## Do's
- Acid green #c8f31d as the single electric accent
- Enormous weight-900 headlines
- Near-sharp 4px corners
- Break the grid deliberately — overlap, rotate, go asymmetric

## Don'ts
- No safe centered layouts — be experimental
- No soft rounded pill buttons
- No second accent color or pastels
- No small timid type
