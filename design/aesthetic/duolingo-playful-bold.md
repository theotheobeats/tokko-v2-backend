# Duolingo — Style Reference
> Playful classroom mascot on white paper

**Theme:** light
**Best for:** bold aesthetic, playful, consumer apps

Duolingo's interface treats the page like a children's storybook: white paper canvas, chubby rounded display type, and a single saturated green that reads as 'correct answer' the moment it appears. Body copy stays calm in mid-gray so the green and its accent blue can do all the emotional work — green for progress and headings, blue for interactive links. Components are pill-shaped or chunky-rounded with thick 2px borders, giving every button the feel of a sticker pressed onto the page rather than a flat UI control.

## Color Palette

| Role | Value | Usage |
|------|-------|-------|
| Eager Green | `#58cc02` | Headings, CTAs, footer band — the dominant brand color |
| Spark Blue | `#1cb0f6` | Interactive links, secondary CTAs |
| Storybook Green | `#d7ffb8` | Soft highlight wash |
| Night Ink | `#000437` | Deep accent text |
| Charcoal | `#4b4b4b` | Hero headings, primary body |
| Pencil Gray | `#777777` | Body paragraphs |
| Faded Gray | `#afafaf` | Outlined button borders |

## Typography

- **Display**: Feather Bold (substitute: Nunito Black), weight 700, 48-64px, -0.02em tracking
- **Body/Nav**: Duolingo Sans (substitute: DIN Next, Nunito Sans), weight 500-700
- Body: 17px, weight 500, line-height 1.18
- Uppercase nav: 15px, weight 700, 0.053em tracking

## Spacing & Shapes

- Button radius: 12px (non-negotiable)
- Link radius: 12px
- Section gap: 80-120px
- Page max-width: 1200px
- 2px solid borders on all outlined elements

## Key Patterns

- Hero: 32px headline in charcoal → green CTA below
- Sections: text-left, illustration-right, single column
- Display headings: 48-64px Feather Bold in #58cc02
- Body text: always #777777 mid-gray — recedes so colored elements lead
- Outline buttons: first-class citizens with 2px #afafaf borders
- Footer: full-bleed green band
- Illustrations: flat 2D mascot characters, never photography

## Do's
- #58cc02 for headings and CTAs that need to read as 'progress'
- Display headlines at 48-64px Feather Bold with -0.02em tracking
- 12px border-radius + 2px solid borders on every button
- Body in #777777 so colored elements lead
- Flat sticker-like surfaces, no gradients or shadows

## Don'ts
- No colored text in body paragraphs
- No sharp corners — even small tags use 12px
- No gradients, shadows, or glass effects
- No Feather at sizes below 48px — display face only
- No secondary palette colors in UI chrome
