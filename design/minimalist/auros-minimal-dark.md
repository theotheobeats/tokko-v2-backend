# Auros — Style Reference
> Abyssal terminal with phosphor glow

**Theme:** dark
**Best for:** tech, gadget, finance

## Color Palette
Deep abyss black, phosphor green glow. Terminal-green accents.

## Typography
Monospaced terminal fonts. Clean hierarchy.

## Spacing & Shapes
Minimal, terminal-window aesthetic.

## Key Patterns
Terminal/console aesthetic. Green phosphor on black. Data-dense layouts with breathing room.

## Do's
Terminal green #00ff00 style accents. Dark canvas. Data-forward.

## Don'ts
No warm tones. No decorative elements.
