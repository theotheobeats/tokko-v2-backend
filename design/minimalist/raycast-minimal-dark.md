# Raycast — Style Reference
> Midnight command center, coral neon

**Theme:** dark
**Best for:** tech, gadget, service

## Color Palette
Canvas: deep charcoal, Accent: coral/orange neon glow. Monochrome dark base with warm highlight.

## Typography
System fonts, geometric. Clean hierarchy with generous spacing.

## Spacing & Shapes
Rounded cards, compact command palette aesthetic.

## Key Patterns
Command palette UX translated to marketing. Spotlight-style search as hero. Feature sections with terminal-like precision.

## Do's
Dark canvas as default. Coral neon for accent only. Clean monospaced labels.

## Don'ts
No multi-column clutter. No bright backgrounds.
