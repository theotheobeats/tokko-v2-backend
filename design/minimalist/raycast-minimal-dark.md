# Raycast — Style Reference
> midnight command center, coral neon

**Theme:** dark
**Best for:** minimal aesthetic, tech, gadget, developer tools

Raycast is a command palette expanded into a page: deep charcoal canvas, razor-clean type, and a single coral (#ff6363) that glows like a hotkey highlight. Everything is compact, rounded just so (12px), and organized with terminal precision. It feels fast — dark, focused, and quietly electric, with the coral reserved for moments that demand action.

## Color Palette

| Role | Value | Usage |
|------|-------|-------|
| Deep Charcoal | `#0f0f11` | Page canvas |
| Panel | `#17181c` | Card and section surfaces |
| Coral Glow | `#ff6363` | Primary CTA, active accents, glow |
| Starlight | `#f5f5f7` | Headlines, primary text |
| Dim Gray | `#9b9ba4` | Body copy, secondary text |
| Hairline | `#26272d` | Borders, dividers |
| Coral Tint | `rgba(255,99,99,0.12)` | Highlight washes, hover states |

## Typography

- **Primary**: Inter (substitute: system-ui), weights 400-600
- Display: 48-64px, weight 600, tracking -0.02em
- Section heading: 30-36px, weight 600
- Body: 15-16px, weight 400, line-height 1.6
- Labels/keys: 12-13px, weight 500, monospace-style, in dim gray

## Spacing & Shapes

- Card radius: 12px
- Button radius: 8px
- Section gap: 88-120px
- Page max-width: 1080px
- 1px #26272d hairline borders; no shadows

## Key Patterns

- Hero: centered command-palette feel — big headline → compact coral CTA
- Cards: #17181c panels on #0f0f11, 12px radius, hairline border
- CTAs: filled coral #ff6363 with subtle glow (box-shadow: 0 0 20px rgba(255,99,99,0.35))
- Feature rows: alternating panels, terminal-precise alignment
- Monospace labels for metadata, tags, and keyboard-style hints

## Do's
- Dark charcoal canvas as the default — never bright
- Coral #ff6363 only for actions and active states
- 12px card radius, hairline borders, compact spacing
- Coral tint washes for subtle emphasis

## Don'ts
- No bright or white backgrounds
- No multi-column clutter — single focused column
- No heavy shadows — glow only on coral accents
- No extra accent colors — charcoal + coral only
