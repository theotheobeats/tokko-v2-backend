# Linear — Style Reference
> dark instrument panel, indigo precision

**Theme:** dark
**Best for:** minimal aesthetic, tech, SaaS, productivity

Linear is a precision instrument: a deep slate canvas, crisp near-white type, and a cool indigo (#5e6ad2) that marks every interactive control. The aesthetic is engineered — tight 8px corners, hairline borders, compact density, and a subtle top-light gradient on panels. It reads as fast, exact, and modern without a single decorative flourish.

## Color Palette

| Role | Value | Usage |
|------|-------|-------|
| Slate Canvas | `#0f1014` | Page background |
| Panel | `#16181d` | Card surfaces with subtle top-light |
| Indigo | `#5e6ad2` | CTAs, links, active states |
| Bright Text | `#f7f8f8` | Headlines, primary text |
| Muted Gray | `#8a8f98` | Body copy, secondary text |
| Hairline | `#23252b` | Borders, dividers |
| Indigo Tint | `rgba(94,106,210,0.12)` | Highlight washes |

## Typography

- **Primary**: Inter (substitute: system-ui), weights 400-600
- Display: 48-64px, weight 600, tracking -0.02em
- Section heading: 30-36px, weight 600
- Body: 15-16px, weight 400, line-height 1.6
- Labels: 12-13px, weight 500

## Spacing & Shapes

- Card radius: 8px
- Button radius: 6px
- Section gap: 96-128px
- Page max-width: 1120px
- 1px #23252b hairlines; panels get a faint inset top highlight

## Key Patterns

- Hero: centered crisp headline → indigo CTA, tight and exact
- Cards: #16181d panels, 8px radius, hairline border, subtle top gradient
- CTAs: filled indigo #5e6ad2, 6px radius, compact padding
- Dense feature grids with hairline separation
- Muted gray body text recedes so indigo leads

## Do's
- Dark slate canvas with cool indigo accent
- 8px radius, hairline borders, compact spacing
- Subtle top-light gradient on panels for depth
- Indigo only for interactive elements

## Don'ts
- No bright backgrounds or warm colors
- No heavy shadows — depth from tint and gradient only
- No decorative illustrations
- No extra accent colors
