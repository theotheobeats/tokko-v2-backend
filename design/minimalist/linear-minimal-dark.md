# Linear — Style Reference
> midnight precision instrument

**Theme:** dark
**Best for:** tech, gadget, tools

## Color Palette
Canvas: #08090a void black, Cards: #0f1011 carbon, Text: #ffffff paper white, Accent: #e4f222 acid lime (used sparingly like a flashlight)

## Typography
Inter Variable, weights 300-590 — tight negative tracking (-0.022em) at 48-72px. Berkeley Mono for code. NO bold weights — precision over volume.

## Spacing & Shapes
6px and 12px radii, 0.5px hairline borders, compact 8-12px paddings. Density: compact.

## Key Patterns
Dark canvas with precision-machined cards. Single electric-lime accent used as functional flashlight — small, high-contrast, signals action. Product UI (kanban boards, issue cards) IS the visual texture. Almost zero decoration.

## Do's
Use acid lime #e4f222 sparingly for primary actions only. Keep weights in 400-510 range. Hairline 0.5px borders instead of shadows. Let product screenshots carry visual interest.

## Don'ts
No shadows on cards. No bold weights. No decorative ornament. No multiple accent colors.
