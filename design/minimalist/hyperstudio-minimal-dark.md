# Hyperstudio — Style Reference
> dark studio void with electric lime

**Theme:** dark
**Best for:** minimal aesthetic, tech, creative tools, portfolios

Hyperstudio is a black studio void lit by a single electric lime (#a3e635): near-black surfaces, crisp white type, and that one acidic green marking every interactive element like a laser pointer. The layout is sparse and gallery-like — lots of void, few objects, hard focus. Corners are minimal (6px), spacing is vast, and nothing competes with the lime.

## Color Palette

| Role | Value | Usage |
|------|-------|-------|
| Studio Void | `#0a0a0a` | Page canvas |
| Panel Charcoal | `#141414` | Card surfaces |
| Electric Lime | `#a3e635` | CTAs, active accents, key highlights |
| Gallery White | `#fafafa` | Headlines, primary text |
| Ash Gray | `#8a8a8a` | Body copy, secondary text |
| Hairline | `#232323` | Borders, dividers |
| Lime Tint | `rgba(163,230,53,0.1)` | Hover washes, highlight fills |

## Typography

- **Primary**: Inter (substitute: system-ui), weights 400-600
- Display: 52-68px, weight 600, tracking -0.03em
- Section heading: 32-38px, weight 600
- Body: 15-16px, weight 400, line-height 1.6
- Labels: 12px, weight 600, uppercase, 0.08em tracking

## Spacing & Shapes

- Card radius: 6px (nearly sharp)
- Button radius: 6px
- Section gap: 100-140px (vast voids)
- Page max-width: 1100px
- 1px #232323 hairlines; no shadows

## Key Patterns

- Hero: huge white headline floating in void → single lime CTA
- Cards: #141414 on #0a0a0a, 6px radius, hairline border
- CTAs: solid lime #a3e635 with dark text — high contrast punch
- Generous negative space — let elements breathe in the dark
- Lime used sparingly, only where action happens

## Do's
- Near-black canvas with one electric lime accent
- Vast negative space — the void is the design
- Lime #a3e635 exclusively for interactive elements
- Sharp 6px corners, hairline borders

## Don'ts
- No second accent color — lime only
- No bright backgrounds or warm tones
- No shadows or gradients
- No cluttered multi-element sections
