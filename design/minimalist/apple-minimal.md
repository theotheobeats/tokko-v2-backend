# Apple — Style Reference
> Cathedral of white space with whispered headlines

**Theme:** light
**Best for:** minimal aesthetic, luxury, product showcases

A vast pale hall where massive weight-700 type hangs in the air, tethered only by pastel product colors and a single blue thread. Oversized SF Pro Display headlines floating on near-white canvas, surrounded by enormous negative space that makes every word feel deliberate. The palette is almost monochrome — text at #1d1d1f, canvas alternating between #ffffff and #f5f5f7 — with a single blue accent (#0071e3) reserved exclusively for interactive moments. Color appears only in the product imagery itself (pastel finishes), never as UI decoration.

## Color Palette

| Role | Value | Usage |
|------|-------|-------|
| Primary Text | `#1d1d1f` | Headlines, body, button labels |
| Secondary Text | `#707070` | Muted labels, nav inactive |
| Canvas White | `#ffffff` | Primary background |
| Canvas Gray | `#f5f5f7` | Alternating section bands |
| Electric Blue | `#0071e3` | Filled CTA buttons ONLY |
| Link Blue | `#0066cc` | Inline text links |
| Ember Orange | `#b64400` | "Nuevo" badge |

## Typography

- **Primary**: SF Pro Display (substitute: Inter)
- Display: 80-96px, weight 700, tracking -1.44px — the signature "enormous headline floating in white"
- Body: 17px, weight 400, tracking -0.022em
- No weight below 400 for body, below 600 for headings

## Spacing & Shapes

- Card radius: 28px (non-negotiable)
- Button radius: 980px (pill)
- Badge radius: 36px
- Section gap: 100-120px
- Page max-width: 1200px

## Key Patterns

- Hero: eyebrow label → 96px headline → single CTA → product image
- Sections alternate between #ffffff and #f5f5f7 — no dividers needed
- Feature cards: 28px radius, no shadow, no border
- Buttons: pill-shaped, #0071e3 fill, appear once per section maximum
- Navigation: 44px sticky bar, backdrop-filter blur

## Do's
- 80-96px display headlines with tight negative tracking
- Alternate white and gray backgrounds for rhythm
- 28px radius on all cards
- #0071e3 for filled CTAs only — never as decoration
- Let product imagery carry all color

## Don'ts
- No shadows on cards
- No borders below 10px radius
- No accent colors beyond #0071e3 and #0066cc
- No decorative gradients on UI surfaces
- No centered body paragraphs
